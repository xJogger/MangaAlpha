# MangaAlpha v3.4.0

本版本新增**单卷（Book）级元数据与单行本封面体系、Komga `database.sqlite` 与开放离线源 v2 多源并集刮削、细粒度 One-shot（单篇）识别**，同步完成**零隐式拆包边界加固、Bangumi 封面拉取可靠性优化、大库分页性能提升**以及**首页与详情页交互精简**。

## 主要变更

### 1. 单卷（Book）级元数据、单行本封面与 Bangumi 离线回填
- **完整单卷元数据模型与 API 输出**：新增 `book_metadata`、`book_thumbnails` 与字段锁位，覆盖卷标题、卷号与自定义排序值（`numberSort`）、简介、发售日、ISBN、多角色作者、标签、外链与 `SeriesGroup` / `StoryArc`，在网页单卷详情页、Komga REST API（`bookDTO.metadata`）与双 OPDS 入口统一输出。
- **Bangumi 单行本（v5）离线匹配与自动升级回填**：离线索引扩展 `bgm_subject_relations` 与 ISBN 索引，新增本地卷号/单行本匹配引擎（支持同卷号多版本共享封面与元数据、系列标题含「外传/番外」防误判、带圈数字 `①–㊿` / 全角数字 / 中文数字显式卷标 / 尾部完结词解析，以及单本短篇 `oneshot_fallback`）。升级后若检测到旧版 v4 离线库，服务启动 5 秒后自动在后台更新至新版离线索引，并按 50 系列/批以纯离线差量方式回填存量已绑系列的单卷元数据与封面（严格保护 `manual`/`agent` 编辑、锁定字段与高优先级外部源）。
- **Bangumi 封面拉取加固**：公共封面拉取改为按代理地址池化复用 HTTP 连接；公共与授权封面拉取统一补充瞬时网络/TLS 断连/`429`/`5xx` 有界自动重试，并将负缓存拆分为永久无图（`404`/`no_icon_subject` 等，5 分钟）与瞬时失败（15 秒短冷却），避免偶发网络波动锁死占位图。

### 2. 多源并集刮削、Komga 数据库离线源与解耦封面导入
- **多源并集模式与独立候选存储**：多源刮削升级为全链并集填充（高优先级源先填、后续源仅补空白字段，不覆盖手工编辑与字段锁；NSFW 按保守并集判断），新增 `series_source_bindings`、`book_source_bindings`、`series_cover_candidates`、`book_cover_candidates` 稀疏表并按书库优先级链排序解析系列与单卷封面。
- **Komga `database.sqlite` 与开放离线源 v2**：支持流式上传本地 Komga `database.sqlite`（过滤已删除条目并仅建系列级 Sidecar 索引，支持首卷缩略图回退）及 `mangaalpha_meta_v2` 离线包作为只读离线数据源；刮削配置新增「匹配时同时导入内嵌封面到本地」（默认关闭），勾选后按原图内容哈希独立落盘至本地封面目录，删除离线源或 `.sqlite` 文件后封面仍保持可用。
- **刮削管理体验优化**：刮削目标书库升级为多选复选框与一键全选，启动操作拆分为「增量匹配」「重试未命中」「全量重匹配」三个独立按钮；调整书库元数据优先级链后自动在后台提示需要重新匹配。

### 3. 细粒度 One-shot（单篇）识别与零隐式拆包约束
- **细粒度 One-shot 对齐**：在保留原有全库单篇开关的基础上，新增书库根目录直放单文件与 `_oneshots`（支持自定义目录名）自动识别，并支持在单卷普通系列详情页手动开关「标记为单篇 (One-shot)」，联合库继承、书架筛选与 Komga API 保持一致。
- **零隐式拆包边界**：明确并在全链路落实零隐式读取原则——扫库、离线刮削、书架与详情浏览绝不隐式打开任何本地/SMB/网盘漫画归档；`ComicInfo.xml` 解析与归档首图提取仅在用户实际阅读时顺带缓存，或由管理员在作品/单卷页显式触发批量任务执行。

### 4. 网页端详情页、首页精简与墨水屏指引更新
- **系列与单卷详情页增强**：系列详情页新增分卷**「列表模式 / 封面模式」**切换及账号默认偏好；单卷详情页支持查看/编辑卷级元数据、切换或上传自定义封面、独立字段锁，并将单卷 `Bangumi #ID ↗` 徽章升级为可点击跳转链接（未开启 NSFW 时自动隐藏受限单卷条目 ID）。
- **首页精简与板块可关闭**：移除首页顶部冗余标题栏与常规态书库快捷条（保留无书库与全部隐藏时的恢复引导卡片）；「账号设置 → 显示偏好」中的首页「继续阅读」「最近更新」「最近入库」数量均新增「关闭」选项，关闭后跳过对应板块渲染与接口请求。
- **文档与指引更新**：更新 `README.md`、`/admin` 概览与 `/account` 账号设置页的墨水屏选型指引（封闭式墨水屏推荐 KOReader + `opdsforcomic.koplugin`，性能较强的 Android 墨水屏推荐 Koharia 并开启无动画模式）；修正 `docs/release-notes/v3.3.0.md` 贡献者链接为 `[@hugo1120](https://github.com/hugo1120)`。

### 5. 大库查询与联合库性能优化
- 新增 `books.effective_number_sort`、`series` One-shot 部分索引与多组分页复合索引；联合库分卷元数据继承改为仅增量处理本次变更系列；将无筛选 `BooksPage` 总数纳入 `ShelfCache` 缓存并去重 `bookDTOs` 的回退系列查询，明显降低大库分页、排序与过滤耗时。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3040099`）均可直接原地升级，首次启动自动完成幂等建表、索引与字段迁移，保留既有书库、阅读进度与封面缓存。
- **旧版 Bangumi 离线库自动迁移**：若当前数据目录仍使用旧版 Bangumi 离线库（v4，缺少单行本关系表），启动 5 秒后将自动在后台拉取并构建新版离线索引，随后分批纯离线差量回填存量已绑系列的单卷元数据与封面；整个过程不阻塞正常阅读，也不会打开任何漫画归档文件。
- 升级前建议按习惯备份数据目录中的 `fake-komga-115.db`。
