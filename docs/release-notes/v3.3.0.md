# MangaAlpha v3.3.0

本版本围绕**个人书库筛选、首页与历史按作品聚合、内置阅读器自动条漫识别、NSFW 开关收敛、书架无限滚动体验（社区 PR #7）**以及 **Komga 阅读进度协议对齐**完成全面体验升级。

## 主要变更

### 1. 书架卡片对齐、筛选栏重构与无限滚动模式（感谢 [@hugo1120](https://github.com/hugo1120) 贡献 PR #7）
- **书架与首页展示打磨**：优化书架筛选栏交互与移动端排版，强化卡片视觉对齐与多账号切换时的 DOM 隔离（账号切换时即时清空旧视图与缓存偏好，避免跨账号残影）。
- **个人书架无限滚动开关**：在「账号设置 → 显示偏好」新增书架无限滚动开关（默认关闭、保持分页；开启后自动触底加载并在随机漫游排序下安全回退分页，不遗漏作品）。

### 2. 个人书库可见性筛选（黑名单制、全端一致、保留直链）
- **按账号独立勾选显示书库**：在 `/account` 新增「选择显示的书库」勾选区与「全部显示」按钮（新增 `user_hidden_libraries` 表）；采用黑名单机制，管理员后续新授权的书库默认自动显示。
- **全端一致隐藏 + 允许直链访问**：隐藏某书库后，该书库在网页首页、`/libraries`、搜索、筛选分面、合集/阅读清单、`/history`、Komga REST（Mihon / Koharia）以及双 OPDS 入口（`/opds/v1.2`、`/api/opds/v1.2`）均不再展示；已收藏或保存的作品/卷/书库直链与阅读进度仍可正常打开。全部已授权书库均被隐藏时，首页与书库页展示友好引导卡片以便一键恢复。

### 3. 首页「继续阅读」与 `/history` 按作品合并
- **聚合后端接口**：新增 `GET /admin/api/bookshelf/continue-reading` 与 `GET /admin/api/bookshelf/history`（自动遵循个人隐藏书库与 NSFW 策略），默认按 `series_id` 合并，开启「合并相同 Bangumi ID」时进一步对非单本且已绑定 Bangumi ID 的多库/多版本作品合并。
- **精简卡片与时间线**：首页「继续阅读」每部作品仅占 1 张卡片并直跳最新在读卷，存在其余在读卷时展示 `另有 N 卷在读` 徽标；`/history` 保持按本地日期分组与同日折叠，新增行内同步「合并相同 Bangumi ID」开关并在跨库子卷上标注来源书库。

### 4. 内置阅读器自动条漫识别（含记忆与桌面端缩放修正）
- **标签收窄 + 元数据方向接入**：恢复 `shouldUseAutoWebtoonMode` 默认开启，收窄长条标签表以去除 `韩漫` / `国漫` / `Manhwa` / `Manhua` / `만화` / `漫画` 等泛标签误触发；接入 `metadata.tags`、`readingDirection`（`VERTICAL` / `WEBTOON` 强制条漫）与 `readingDirectionLock`（锁定横翻时抑制自动条漫）。
- **前 5 页客户端高宽比探针 + 记忆**：对未刮削/无标签的长条漫采样前 5 页（`>=4` 页自动跳过非长图封面，忽略 `<200px` 装饰图与宽跨页，满足 `>=2` 页高宽比 `>=2.5` 或单页 `>=3.5` 即自动切入 Webtoon 模式），自动记住 `fk115_autoWebtoonDetected` 并同步到用户设置，同时严格让位于用户手动切换的阅读模式。
- **桌面端 Webtoon 缩放修正**：桌面端（`>=900px`）进入 Webtoon 模式且用户未自定义全局缩放模式时，默认回退为按宽适配（`WIDTH`），避免超长条漫被压扁到单屏高度。

### 5. NSFW 开关去重与 Komga 进度语义对齐
- **NSFW 开关统一收口**：移除「缓存与设置」与「元数据刮削」两处重复开关并改为静态引导，统一为「管理员在用户管理授予权限 + 各用户在 `/account` 自主开关」（后端保留 `show_nsfw` / `showNsfw` 兼容别名并修复 `PUT /admin/api/bangumi/config` 返回旧值问题）。
- **Komga `PATCH /api/v1/books/{id}/read-progress` 单字段对齐**：已知总页数（已索引）时将越界 `page` 裁剪至 `[1, pageCount]`，省去 `completed` 时自动按末页推断完成状态，单传 `{completed: true}` 时自动补齐 `page = pageCount`；未索引（`pageCount == 0`）时不触发后台解包并安全落库；联合库同步镜像最终值。
- **文档补充**：在 `README.md`「尚不支持」中明确补充 PDF 等非图片流式容器格式说明。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3030099`）均可直接原地升级，首次启动自动创建幂等表 `user_hidden_libraries`，不改动存量书库与阅读进度。
- 升级前建议按习惯备份数据目录中的 `fake-komga-115.db`。
